# Portfólio — Audria Mascarenhas

Projeto estático para editar no VS Code com Codex. Não exige Node, frameworks ou instalação de dependências.

## Como visualizar

Abra a pasta `portfolio-audria` no VS Code. Use a extensão **Live Server** e escolha **Open with Live Server** no arquivo `index.html`, ou abra `index.html` diretamente no navegador.

## Estrutura

- `index.html`: página inicial e galeria de projetos.
- `sobre.html`: Sobre mim.
- `curriculo.html`: currículo.
- `projetos/eva.html`: estudo de caso EVA.
- `assets/css/global.css`: fonte, estilos compartilhados e identidade visual.
- `assets/css/home.css`, `sobre.css`, `curriculo.css`, `eva.css`: estilos específicos.
- `assets/js/home.js`: filtros da galeria (separado do HTML).
- `assets/images/`: imagens do portfólio.

## Atenção antes de publicar

- A foto `assets/images/sua-foto.jpg` ainda precisa ser adicionada.
- As prévias ilustrativas dos projetos são placeholders; substitua pelas capturas reais.
- Alguns cards na Home são espaços reservados, não projetos concluídos.
- A página EVA contém aviso de protótipo conceitual e imagens ilustrativas.
- Links externos de fontes e alguns ícones do currículo precisam de internet.

## Direção visual

Fonte Figtree; fundo cinza-claro; visual minimalista e editorial; logo com xícara de café; menu Sobre mim, Currículo, Contato. Não incluir programação/front-end como competência profissional.
